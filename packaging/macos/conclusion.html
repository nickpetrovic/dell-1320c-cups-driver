The driver is installed

To add your printer, open Terminal and run the following command, with your printer's address in place of the example:

sudo dell1320c add 192.168.0.80 --default

This selects Tray 1 so that jobs don't go to the manual feed slot. You can also add the printer in System Settings → Printers & Scanners and choose Dell Color Laser 1320c as the driver.

If print queues already used this driver, the installer updated them to the new version. If CUPS was not running, update them later with sudo dell1320c refresh.

To remove the driver later, run sudo dell1320c uninstall.
